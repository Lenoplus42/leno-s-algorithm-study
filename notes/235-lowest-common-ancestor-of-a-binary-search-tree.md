[235. Lowest Common Ancestor of a Binary Search Tree](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/)

# 1. 核心直觉

**从根开始，只有当 `p、q` 都在同一棵子树里时，才能继续往下找；第一次不能往同一侧下降的位置，就是最低共同祖先。**

BST 中，左子树的所有值都小于当前节点，右子树的所有值都大于当前节点。因此，比较大小就能判断两个目标是否在同一侧。

# 2. 具体做法

始终保持：当前节点的子树同时包含 `p、q`。

1. 两者都严格小于当前值：都在左子树，左边还有更低的共同祖先，往左走。
2. 两者都严格大于当前值：同理，往右走。
3. 否则，直接返回当前节点：两者分居两侧，或当前节点就是其中一个目标；再往下就无法同时包含它们。

**下降条件必须是严格的 `<` 或 `>`。** 节点可以是自己的祖先；遇到其中一个目标时，答案已经确定，使用 `<=` 或 `>=` 会继续下降，把这个目标留在子树外。

不需要交换 `p、q`，也不需要记录候选答案；用一个指针沿树向下走即可。

时间复杂度 **O(h)**（`h` 为树高），额外空间 **O(1)**。
