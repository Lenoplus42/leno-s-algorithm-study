# 最小化最长连续相同字符段

给定仅含 `a`、`b` 的字符串 `s`，最多翻转 `k` 个字符，返回能得到的最小最长连续段长度。

**直觉：先猜最长段允许多长，再计算把所有长段切开需要几次翻转，寻找次数够用的最小上限。**

- **把求最优变成判断能否做到**：固定上限 `limit`，逐段计算所需翻转次数，总和不超过 `k` 就可行。
- **上限至少为 2 时逐段计算**：长度为 `L` 的一段，每 `limit + 1` 个相同字符至少要翻转一个；可以安排切点使各段不超长，需要 `L // (limit + 1)` 次。
- **上限为 1 单独判断**：翻转可能与邻段连起来，不能独立算；整个字符串只能是 `abab…` 或 `baba…`。与前者不同的位置有 `diff` 个，与后者就有 `len(s) - diff` 个，较小值不超过 `k` 就返回 1。
- **二分最小可行上限**：放宽上限只会更容易，因此可行性从“否”变成“是”；在 2 到原最长段长度之间，能做到就缩小右边界，做不到就增大左边界。
