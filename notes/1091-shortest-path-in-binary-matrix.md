[1091. Shortest Path in Binary Matrix](https://leetcode.com/problems/shortest-path-in-binary-matrix/)

在 `n × n` 网格中从左上角走到右下角：`0` 可走、`1` 是障碍，每次可向周围八个方向移动。返回最短路径经过的格子数，无法到达则返回 `-1`。

# 1. 核心直觉

**每步代价相同，先探索一步能到的，再探索两步能到的，第一次发现一个格子时就已经找到了到它的最短路径。**

FIFO 队列保证按距离从近到远探索，这就是 BFS。DFS 不能保证第一次找到的路径最短。

# 2. 具体做法

1. 起点或终点被堵，直接返回 `-1`。否则将 `(0, 0, 1)` 入队：题目数格子，起点距离为一。
2. 每次取出 `(行, 列, 距离)`，若为终点就返回距离。
3. 检查八个邻居，只将范围内、可走且未访问的格子入队，距离加一。入队时立即标记，避免重复加入。
4. 队列耗尽仍未到终点，返回 `-1`。

用 `seen` 保存访问位置，不修改输入。`[[0]]` 返回 `1`；对角线可以移动。这里第一次发现即可入队，不像拓扑排序需要等待所有前置条件完成。

每个格子最多入队一次，每次检查八个邻居。时间和额外空间均为 **O(n²)**。
