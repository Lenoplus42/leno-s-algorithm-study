# 1392. Longest Happy Prefix

**直觉：前缀和后缀是在比较两段文字；已经确认相同的部分不用重比，只需要看接下来的字符能不能继续相同。**

- **从短到长看字符串**：每加入一个字符，求一次当前的最长相等前后缀。
- **先尝试延长**：上一轮相等的前后缀，如果接下来的字符也相等，就一起增长一位。
- **延长失败就换短的**：最长的那对接不上，就尝试原本也相等的、更短的一对。
  - 先试旧的最长那对，因为我们想要最长的新答案。
  - 它接不上，只代表**这一对**不能延长；更短的旧配对可能接得上，因为它要比较的前缀下一字符不同。
  - 因此，接下来找的是**旧字符串中下一对更短、但仍然相等的前后缀**，再用同一个新字符尝试延长。
- **记录结果来省掉重找**：之前算过的答案，能告诉我们下一对更短的候选在哪里；`pi` 就是这些记录。
