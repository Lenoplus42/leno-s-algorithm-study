# Kac Ring 1：单步模拟与常数时间颜色查询

N > 0 个位置按顺时针编号，初始每个位置有一个白球，M 个互不重复的位置被固定标记。`step()` 让所有球顺时针移动一格，离开标记位置的球翻色；`color()` 在 O(1) 时间返回 `(W - B) / N`。

# 1. 核心直觉

**直觉：整体移动只记偏移量，只有经过标记的球需要改颜色；翻色时顺手维护白球数。**

# 2. 具体做法

- **按球编号存颜色**：`is_white[i]` 始终记录 i 号球的当前颜色，不随位置搬动数组。`offset` 是累计步数对 N 取模。
- **从标记位置反推球编号**：球 i 当前位于 `(i + offset) % N`，所以位置 p 上的球是 `(p - offset) % N`。这一步找的是球，颜色直接从数组读取。
- **翻色时维护数量**：白变黑时 `white_count -= 1`，黑变白时加 1。先处理所有出发位置，再增加偏移量；不需要重新遍历计数。
- **查询直接算**：黑球数是 `N - white_count`，所以结果为 `(2 * white_count - N) / N`。

初始化 O(N + M)，`step()` O(M + 1)，`color()` O(1)，空间 O(N + M)。无标记时始终全白；全部标记时每步所有球翻色。
