# Kac Ring 2：任意步数跳转与常数时间颜色查询

N > 0 个位置组成环，初始全白，M 个互不重复的位置被固定标记。每步所有球顺时针移动一格，离开标记位置时翻色。实现 `step()`、前进非负整数 k 步的 `step_k(k)` 和返回 `(W - B) / N` 的 `color()`；跳步不能逐步模拟，颜色查询要求 O(1)。本解法允许增加初始化成本。

# 1. 核心直觉

**直觉：系统最多走 2N 步就恢复原状，提前存下一个周期的白球数，跳步就变成移动查表下标。**

# 2. 具体做法

- **一圈决定周期**：每个球走 N 步回到原位，且经过全部 M 个标记。M 偶数时原色恢复，N 是一个周期；M 奇数时全部反色，2N 是一个周期，不要求这是最小周期。
- **只模拟前 N 步**：按球编号保存颜色，用偏移量反推每个标记处的球，翻色时维护白球数；表中存第 0 到 N-1 步的数量。
- **奇数标记时补后半段**：从任意时刻再走 N 步，所有球颜色相反，因此 `W(t + N) = N - W(t)`。前半段算好后，将每个数变为 `N - count` 并追加。例如 N=4、单个标记时，`[4, 3, 2, 1]` 后追加 `[0, 1, 2, 3]`。
- **跳步只改阶段**：`phase = (phase + k) % period`；查询从表中取 W，返回 `(2W - N) / N`。仅更新位置偏移量会漏掉途中翻色，必须用完整状态的周期。

初始化 O(N(M + 1))，`step()`、`step_k()`、`color()` 均为 O(1)，空间 O(N + M)。时间按整数运算 O(1) 计算；若另要求初始化 O(N + M)，本方案不满足。k=0 保持原状态，跨越多个周期仍只需取模。
