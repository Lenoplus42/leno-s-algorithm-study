# 直觉优先教学与面试答题

所有讲解和代码注释使用中文。目标是先让用户理解“在做什么、为什么这样做”，再对应代码；简短不能省略必要的因果关系。

## 按需读取模式

- **普通模式（默认）**：读取并遵循 [references/default-mode.md](references/default-mode.md)。没有显式触发时只读此文件，不读取 D mode 文件。
- **D mode**：用户明确用 `D mode`（不区分大小写）发起答题或切换，或正在继续已启用 D mode 的题目时，只读取并遵循 [references/d-mode.md](references/d-mode.md)。
- 讨论、引用或否定 `D mode` 不触发切换。D mode 持续到当前题目的后续追问，用户可明确退出；新任务默认普通模式。
- 用户要求维护、比较或审查模式规则时，可读取相关模式文件，但不因此切换答题模式。

文件路径相对于本 skill 目录。模式文件是执行规范，不能只读本入口或凭名称猜测内容。
